# Task for the lead

You lead a run that has the twelve units in UNITS.md. Choose how to dispatch each unit, using only the lines in ROUTE_MENU.md.

Write a register with one line per unit. Each line cites exactly one menu line as `ROUTE_MENU.md:` followed by the line number, then one short reason. Cite a line for every unit and cite no second line for any unit.

Read only UNITS.md and ROUTE_MENU.md in this directory.
