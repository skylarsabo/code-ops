# Evals and calibration

Charter: deterministic regression evals, judgment fixtures, and the calibration graph. Excludes the workflow configuration that schedules them.

Deterministic Node evals are merge evidence. Judgment fixtures measure model behavior and remain separate from merge gates because model output varies. Answer keys stay outside the context handed to an evaluated skill. The calibration graph preserves only sanitized, machine-parseable lessons from private runs.

The action-pin regression suite attacks the dependency boundary directly. It covers quoted and anchored scalar forms, block-scalar decoys, reusable workflow subpaths, recursive local composite actions, source overlap, and setup-node step ownership. Flow or JSON syntax, hidden nested dependencies, mutable or unlisted references, incomplete review metadata, unsafe paths, and any bypass of the Node version file must fail closed.

The new orchestration substrate has direct regression coverage. `run-contract` exercises versioned contracts, scope conflict rejection, dependency cycles and ordering, journal replay, retry limits, and acceptance. `context-snapshot` covers exact-state identity, cache reuse, untracked policy, drift, Unicode renames, aliased-root symlink containment, and hidden-index refusal during preparation and replay. `context-bundle` covers scope selection, import neighbors, Atlas freshness and excerpt budgets, final serialized byte counts, empty- and broad-context markers, and byte-budget markers.

Long-horizon runtime coverage pins capability receipts, ignored and unlinked capability output, Run Contract v3 policy, bounded stable-prefix compilation, non-regular index rejection, minimized metrics provenance, checkpoint/replan/resume replay, drift refusal, cache telemetry, portable and physical authority aliases, and exact Git object-ID lengths. Local-review coverage attacks dirty state, hidden index flags, revision-expression bases, tracked-path case aliases, physical path aliases, lossless Windows file identity, duplicate reviewers, forged chains, local and unfetched remote base movement, and exact feature-tip publication. Judgment orchestration covers hidden fixture state, one canonical matrix, answer-key-free worker units, distinct floor models, explicit execution policy, linked path refusal, tracked-path case aliases, portable and physical output aliases, write-free rejection, canonical expansion, and deterministic receipt replay.

Atlas regression coverage includes the real squash lifecycle, not only a forged missing pin. A staged scoped state stays fresh through commit and squash after the feature history is pruned. Hidden staged divergence, unstaged stamping, changed scope declarations, and assume-unchanged, skip-worktree, or submodule checkout ambiguity all fail safe. The submodule case pins behavior even when local Git configuration ignores submodule changes.

Documentation regressions now test generic hub discovery, structural-error and vacuous-source rejection during planning, interior glob matching such as `plugins/*/skills/**`, installed sibling-script resolution, and manifest-routed citation scanning. Vault fixtures distinguish published-reference exemptions from working notes. Link fixtures cover Markdown and Obsidian resolution, explicit collection indexes, rejected hub-internal directory targets, verified Markdown heading fragments, ambiguous basenames, wikilink headings, block IDs, aliases, and code examples. A citation gate still rejects absent targets, out-of-range lines, and inverted ranges while skipping fenced examples; bracket syntax and interior directory spaces are deliberate parse cases.

The cost estimator counts only final-result records at the stable result schema version, rather than assuming a contract-version match makes historical cost data comparable. The calibration graph is append-only source with a rendered table. Graph validation and table drift checks run against the real store. Do not hand-edit the table or treat an isolated fixture score as evidence of production quality.

The 228-case Windows record runner is synthetic by policy. It exercises manifest partitioning, exact-case deterministic identity, genesis and incremental admission, authority-batch coverage, v2 migration, native append, CommonMark citation boundaries, ordered normalization, literal pathspecs, linked-path rejection, hub-renamed history, clone-wide and ownerless-lock recovery, curation chains, inventory completeness, immutable drift, mutable evidence, semantic projection, locator provenance, pointer eligibility, and tombstones without copying adopter repository contents. It verifies write-free empty deltas, stale and consumed receipt refusal, receipt-slot versions, evidence-before-pending failure order, transactional rollback, curation of incrementally admitted records, and rejection of historical paths relabeled as native. Adversarial cases pin missing or misplaced review receipts, genesis-source disagreement, manufactured migration provenance, unreachable batch sources, malformed references, exact coverage, predecessor bindings, false migration genesis, cross-platform stale-lock identity, lost-lease fatality, release-result preservation, and post-write restoration. Cross-platform cases separate canonical LF, pre-existing CRLF, binary, custom clean/smudge filters, checkout-transformed worktree bytes, and historical blobs above the batch ceiling. Current governed blobs remain bounded. Manifest mutations pin every v2 collection and legacy rule plus non-empty extraction receipts. Vault fixtures prove generated-path exemptions are exact rather than version-wide.

History regressions cover promotion, delete-and-readd, rename-back, path reuse, and content-preserving squash. A defensive fixture pins the Windows process-argument budget for long Git paths. An ordinary descendant edit-and-revert still fails. Receipt cases cover digest mismatch, committed replacement, candidate removal, forged `sourceHead`, and risk relabeling. Inventory rewrites exercise the historical monotonicity failure path. Refused adoption must leave no generated files.

Invalid classification is tested with complete and shallow history. Manifest coverage proves that non-string scopes fail. Untracked casing aliases remain visible, and untracked files cannot satisfy exact selectors.

The traceless eval keeps box-drawing trees and text-default symbols clean while retaining presentation emoji and keycap coverage. A temporary Git history proves inherited dash density can be separated only through an ancestor commit. It rejects arbitrary self or copied baselines, unrelated commits with identical trees, untracked recreations, `--git` mixing, and any attempt to suppress a hard-tell category.

The façade eval now pins the migrated domain end to end. Every `scan` verb must answer `--help` with the same exit code, stdout, and stderr as its own script, so a shared flag parser cannot quietly reword a gate. The lint eval adds the façade-reference cases: an unbundled verb script and a verb outside the table both fail closed, and the same reference passes once the script is bundled.

The context-audit eval is the first measurement regression. It pins the transcript parser (usage deduplicated by message id, subagent threads apart), the sanitized-versus-raw output rule, and the `SessionEnd` receipt hook (one row, silent stdout, fail-open) against a synthetic fixture that carries no real transcript content.
