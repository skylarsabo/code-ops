# Evals and calibration

Charter: deterministic regression evals, judgment fixtures, and the calibration graph. Excludes the workflow configuration that schedules them.

Deterministic Node evals are merge evidence. Judgment fixtures measure model behavior and remain separate from merge gates because model output varies. Answer keys stay outside the context handed to an evaluated skill. The calibration graph preserves only sanitized, machine-parseable lessons from private runs.

The action-pin regression suite attacks the dependency boundary directly. It covers quoted and anchored scalar forms, block-scalar decoys, reusable workflow subpaths, recursive local composite actions, source overlap, and setup-node step ownership. Flow or JSON syntax, hidden nested dependencies, mutable or unlisted references, incomplete review metadata, unsafe paths, and any bypass of the Node version file must fail closed.

The new orchestration substrate has direct regression coverage. `run-contract` exercises versioned contracts, scope conflict rejection, dependency cycles and ordering, journal replay, retry limits, and acceptance. `context-snapshot` covers exact-state identity, cache reuse, untracked policy, drift, Unicode renames, aliased-root symlink containment, and hidden-index refusal during preparation and replay. `context-bundle` covers scope selection, import neighbors, Atlas freshness and excerpt budgets, final serialized byte counts, empty- and broad-context markers, and byte-budget markers.

The orchestration regressions also pin optional token budgets, explicit frontier specialists, shared partial-acceptance parsing, and runtime status across checkpoint, resume, and replan. The worker-brief eval proves invariant-prefix ordering, byte-deterministic receipts, source and output alias refusal, invalid UTF-8 rejection, and overflow without truncation. Context-bundle coverage includes the bounded worker view, and cost coverage keeps receipt attribution and operator-supplied price math separate from invoice claims.

The submodule case pins behavior even when local Git configuration ignores submodule changes.

Shipped-reference lint cases mostly pair a failure with a pass that changes one thing.
