# Evals and calibration

Charter: deterministic regression evals, judgment fixtures, and the calibration graph. Excludes the workflow configuration that schedules them.

Deterministic Node evals are merge evidence. Judgment fixtures measure model behavior and remain separate from merge gates because model output varies. Answer keys stay outside the context handed to an evaluated skill. The calibration graph preserves only sanitized, machine-parseable lessons from private runs.

The new orchestration substrate has direct regression coverage. `run-contract` exercises versioned contracts, scope conflict rejection, dependency cycles and ordering, journal replay, retry limits, and acceptance. `context-snapshot` covers exact-state identity, cache reuse, untracked policy, drift, Unicode renames, and aliased-root symlink containment. `context-bundle` covers scope selection, import neighbors, Atlas freshness and excerpt budgets, final serialized byte counts, empty- and broad-context markers, and byte-budget markers.

Atlas regression coverage includes the real squash lifecycle, not only a forged missing pin. A staged scoped state stays fresh through commit and squash after the feature history is pruned. Hidden staged divergence, unstaged stamping, changed scope declarations, and assume-unchanged, skip-worktree, or submodule checkout ambiguity all fail safe. The submodule case pins behavior even when local Git configuration ignores submodule changes.

Documentation regressions now test generic hub discovery, structural-error and vacuous-source rejection during planning, interior glob matching such as `plugins/*/skills/**`, installed sibling-script resolution, and manifest-routed citation scanning. Vault fixtures distinguish published-reference exemptions from working notes. Link fixtures cover Markdown and Obsidian resolution, explicit collection indexes, rejected hub-internal directory targets, verified Markdown heading fragments, ambiguous basenames, wikilink headings, block IDs, aliases, and code examples. A citation gate still rejects absent targets, out-of-range lines, and inverted ranges while skipping fenced examples; bracket syntax and interior directory spaces are deliberate parse cases.

The cost estimator counts only final-result records at the stable result schema version, rather than assuming a contract-version match makes historical cost data comparable. The calibration graph is append-only source with a rendered table. Graph validation and table drift checks run against the real store. Do not hand-edit the table or treat an isolated fixture score as evidence of production quality.

The record-collection runner is synthetic by policy. It exercises manifest partitioning, exact-case deterministic identity, adoption, native append, CommonMark citation boundaries, ordered normalization, hub-renamed history, curation chains, immutable drift, mutable evidence, semantic projection, pointer eligibility, and tombstones without copying adopter repository contents. Manifest and vault runners separately pin the v3/v4 and v1/v2 compatibility matrix.
