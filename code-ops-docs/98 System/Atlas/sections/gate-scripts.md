# Gate scripts and hooks

Charter: repository gates, renderers, orchestration compilers, and hook behavior. Excludes workflow scheduling and eval fixtures.

The default posture is fail closed. Usage errors, malformed configuration, drifted generated output, untrusted documentation records, and invalid receipts fail. Process-risk advisories remain explicit exceptions. Atlas ambiguity is fail-safe: the checker calls a section stale rather than treating uncertain judgment as current. Digest-backed sections bind exact scopes, the staged index, and the index-to-worktree delta; commit pins remain diagnostic and legacy-compatible.

Model judgment no longer depends on repository-hosted review workflows. `local-review-gate.mjs` binds a clean feature branch, base, HEAD, binary diff, changed paths, two independent report identities, and a hash-chained receipt set. Ignored authority outputs cannot portably alias tracked Git paths. Physical identity retains lossless device and inode values on Windows. A shared index guard rejects assume-unchanged, skip-worktree, and submodule ambiguity before either local review or judgment planning reads worktree bytes. Publication verifies live remote base and feature refs and binds the destination repository to that same remote. `judgment-evals.mjs` compiles answer-key-free worker units from one matrix and binds declared model and execution policy to deterministic score receipts.

GitHub Action dependencies have one reviewed lock at `.github/actions-lock.json`. The action-pin checker requires exact lowercase commit SHAs, full semantic-version annotations, complete review metadata, and `.node-version` as the only setup-node runtime authority. It scans repository workflows, shipped examples, reusable workflows, and the metadata of reachable local composite actions with physical-path deduplication. Unsupported YAML forms, mutable or unlisted actions, unsafe local paths, and policy drift fail closed.

The run contract turns multi-agent work into a bounded artifact. It validates routing floors, dependency order, parallel write separation, retry limits, acceptance ownership, optional per-unit token budgets, and final proof. Version 2 binds exact context and version 3 adds the host/runtime boundary. Version 4 records the session model as its lead, warns rather than fails when that lead sits below strong, and requires a real disjoint parallel wave, independent validation, and nonempty operative evidence. An `orchestration.singleUnitReason` of at most 20 words lowers the operative and parallel floors to one; it fails when the plan still sets both floors to two or more. Its task-based routing policy records each selection rationale and preserves kind floors. One bounded frontier peer needs an explicit exception and a linked lead-owned blocking criterion. Contracts without that policy no longer force units below the lead tier. A valid calibration block, which still requires high lead effort, binds assess-only calibration arms (b) and (c). It requires read-mode units and artifacts outside every scope, and units may run at the lead tier but never above it. It rejects a lead model that also serves the frontier rung, because that arm cannot measure a strong-versus-frontier gap. Every new substantive run uses version 4; versions 1 through 3 remain readable only for replay. Capability initialization rejects Git-visible or linked output before writing raw provenance. Capability and receipt paths cannot collide portably or resolve to one physical file. Stable-prefix sources must be regular stage-0 files without linked components. Runtime replay accepts only exact SHA-1 or SHA-256 Git object IDs, and the chain retains no raw host labels. The runtime engine checkpoints, resumes, and replans through one locked hash chain while reusing contract, ledger, partial acceptance, bundle, Atlas, and handoff authorities. Runtime status exposes pending work, unresolved criteria, drift, and observable token-budget overruns without treating a checkpoint as completion.

The dispatch journal is the runtime authority for actor and state continuity. It accepts only legal transitions, requires dependencies to complete before activation, keeps one recorded host or session actor identity across a unit attempt, and prevents one actor from satisfying independent discovery and validation roles. Under a version 4 contract, `add` keys each row by its contract unit, requires an actor, and binds the journal to the contract run. Checkpoint, replan, resume, and verify reconcile in flight: they reject permanent journal violations and admit planned units that have not reported. Finalization stays strict. Actor identifiers are auditable runtime records, not cryptographic identity attestations.

`attack-chain-graph.mjs` compiles security hypotheses, primitives, collisions, blocked terminals, resumptions, and validated impact into one graph. It proves artifact confinement and hashes, exact glob intersections, unique family launches, anti-convergence history, distinct implementation-layer receipts, realistic success conditions, and independent validation. Final mode rejects every open or off-chain node; in-progress mode exposes and ranks only graph-reachable open resumptions.

The cost estimator is a planning advisory, not accounting evidence. It projects dispatch shape from finalized historical runs. When an operator supplies a dated price snapshot, it separately attributes observed runtime tokens and a subtotal to receipt-bound models. Missing observations remain unknown, and the subtotal is never presented as a provider invoice.

The context compiler separates reusable structural indexing from unit context. A snapshot hashes visible Git state and generator identities, then caches the repository map, import graph, and optional Atlas report by content address. It preserves Unicode rename and copy destinations, canonicalizes aliased roots before symlink containment checks, and parses live Atlas freshness output. A bundle selects scoped files, import neighbors, visible changes, and fresh Atlas excerpts. Its worker view preserves indexed metadata and graph edges in stable columns while binding the canonical bundle. Reported byte counts cover final serialized payloads. Empty scope, broad scope, and byte overflow fail explicitly instead of producing misleading or truncated context.

Command output has a compressor of its own. `digest.mjs` spawns a command, keeps the raw bytes in a home-directory receipt store, and prints a view compressed by output shape rather than by command name. Nine detectors cover diffs, diagnostics, test runs, stack traces, logs, tables, listings, JSON, and an unrecognized fallback that passes through under a line cap. The compression is loss-bounded by contract: the must-keep line set is fixed before any stage runs, and no stage may drop or rewrite a line in it. Every elision prints the exact command that recovers it, and the child's exit code always becomes the digest's. A `--cwd` names the directory the command runs in, so a caller that would have written `cd <dir> && <cmd>` keeps the no-shell contract. The `digest-rewrite.mjs` hook now reaches it from a `PreToolUse` Bash stage, but only in a repository that set `CODE_OPS_DIGEST`; everywhere else it still runs only when an operator invokes it.
