This folder is the documentation hub for the code-ops repository, and its Obsidian vault. It holds the handbook, the technique pages, the guides, the manifest-owned references, the design notes, the decisions, and the run notes.

Start at [00 Home.md](00%20Home.md), which maps the hub by intent. In Obsidian, choose **Open folder as vault** and pick this folder, not the repository root.

Read [Standard.md](Standard.md) for the layout, the frontmatter, and the routing table that says where new work goes. Run `node scripts/docs-manifest.mjs check` from the repository root before trusting a manifest-owned page.
