- Resident context on Claude no longer double-counts an advisor turn. A turn with an advisor call writes a top-level usage that sums the main-model iterations, so the count read 229,797 where the real figure was 115,833. `residentContext` now reads the last `message` entry of `usage.iterations`, and the top-level figure stands when no such entry exists. This removes the false handoff cards and ceiling denials the doubled count caused.
- The handoff card on Claude and Codex now fires at two checkpoints measured against the auto-compaction window W: an early checkpoint at 60 percent of W and a final checkpoint before auto-compaction at 80 percent of W. W is `CODE_OPS_COMPACT_WINDOW` on any non-Grok host, else `CLAUDE_CODE_AUTO_COMPACT_WINDOW` on Claude, else 200,000. Each stage fires once per arm and re-arms below 60 percent. The card asks for a checkpoint only and never asks for `/compact` or a handoff. The fixed 150,000-token bands now apply to Grok only, and Grok behavior is unchanged.
- The context-ceiling dispatch gate is now off by default on Claude, Codex, and OpenCode, where host auto-compaction holds context. `CODE_OPS_CONTEXT_CEILING` set to an integer of at least 150000 opts in, and its denial asks only for `/code-ops-suite:handoff assess`. Grok keeps its 200,000-token default and its `/compact` flow.
- The global contract, the handoff skill, the README files, the contracts, infrastructure, and measurements documents, and the generated host distributions state the new checkpoint and ceiling rules.
