- The dispatch guard gains a tenth behaviour, the lead inline-streak guard. On the main thread it counts consecutive hands-on tool calls (Bash, Read, Grep, Glob, Edit, Write, MultiEdit, NotebookEdit) per session. A dispatch or a new operator prompt resets the count. At `CODE_OPS_LEAD_STREAK` calls (default 8) and each multiple, it adds one advisory that names the batch, probe, mech, or implementer alternative, and logs a `lead-streak` decision row with counts only. `CODE_OPS_LEAD_GUARD=deny` makes each threshold hit a denial; `off`, `0`, or `false` disables it. The default is advisory, so the decision rows measure firing before deny is considered. A usage audit of 2026-10-15 to 2026-10-19 found lead streaks of five or more single-Bash turns in 52% of lead turns.
